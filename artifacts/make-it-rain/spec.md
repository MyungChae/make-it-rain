# make-it-rain — spec

## 개요

하늘에서 떨어지는 돈을 땅에 닿기 전에 클릭해 점수를 쌓는 60초 캐주얼 게임. 함께 떠 있는 비누방울을 잘못 클릭하면 점수가 깎이므로, 사용자는 빠르게 돈과 비누방울을 구분해 정확히 클릭하는 반응성·식별력 게임을 경험한다.

## 범위

### 포함
- 메뉴 화면에서 게임을 시작하고 결과 화면에서 다시 시작할 수 있다
- 60초 동안 돈 3종(동전·지폐·금괴)과 비누방울 2종(작은·큰)이 화면 위에서 떨어진다
- 객체를 클릭하면 종류별로 정해진 점수만큼 현재 점수가 변한다
- 시간이 지날수록 객체 생성·낙하 속도가 점진적으로 빨라진다
- 라운드 중 누적 점수가 200점 배수 임계점(200·400·600…)을 처음 넘을 때마다 부스터가 1개씩 충전된다
- 부스터 버튼을 누르면 3초간 돈만 대량으로 떨어지는 "부스터 모드"가 발동된다 (비누방울 생성 중단)
- 라운드 종료 시 최종 점수와 종류별 잡은 개수가 표시된다
- 같은 브라우저의 최고 점수가 유지되고, 갱신 시 표시된다
- 시스템 설정에 따라 라이트·다크 테마가 자동 적용된다
- 모바일(터치)과 데스크톱(마우스) 모두에서 동일하게 동작한다

### 제외
- 로그인·회원·닉네임 (캐주얼 도구이며 글로벌 리더보드 범위 밖)
- 글로벌 리더보드 (별도 서버·DB가 필요하므로 추후 결정)
- 일시정지 / 이어하기 (60초 단발 라운드라 흐름을 끊을 필요 적음)
- 사운드 / BGM (시각 피드백으로 충분한 1차 범위, 추후 추가 검토)
- 멀티플레이·실시간 경쟁
- 데일리 챌린지·업적·미션
- 광고·과금

## 시나리오

### 1. 메뉴 화면 진입

- **Given** — 게임 페이지를 처음 열었다
- **When** — 페이지 로드가 끝났다
- **Then** — "시작" 버튼과 게임 제목, 그리고 (있다면) 최고 점수가 보이는 메뉴 화면이 표시된다

성공 기준:
- [ ] 페이지 로드 → "시작" 버튼이 보인다
- [ ] localStorage에 최고점 없음 → 메뉴에 최고점 영역이 표시되지 않거나 "최고 점수 -"로 표시된다
- [ ] localStorage에 최고점 N점 저장됨 → 메뉴에 "최고 점수 N"이 표시된다

### 2. 라운드 시작 (카운트다운)

- **Given** — 메뉴 화면이 표시된 상태
- **When** — "시작" 버튼을 클릭한다
- **Then** — 화면 중앙에 3 → 2 → 1 카운트다운이 차례로 표시된 뒤 게임이 시작된다

성공 기준:
- [ ] "시작" 클릭 → 메뉴가 사라지고 카운트다운 "3"이 보인다
- [ ] 카운트다운이 1초 간격으로 3 → 2 → 1로 바뀐 뒤 사라진다
- [ ] 카운트다운이 끝난 시점에 점수 0, 남은 시간 60초가 화면 상단에 표시된다
- [ ] 카운트다운이 끝난 직후부터 객체가 화면 위에서 떨어지기 시작한다

### 3. 돈 클릭으로 득점

- **Given** — 라운드가 진행 중이고 화면에 돈(동전·지폐·금괴) 하나 이상이 떨어지고 있다
- **When** — 떨어지는 돈 객체 위를 클릭(또는 터치)한다
- **Then** — 해당 객체가 화면에서 사라지고, 종류에 해당하는 점수만큼 현재 점수가 증가한다

성공 기준:
- [ ] 동전 클릭 → 현재 점수가 +5 증가하고 동전이 사라진다
- [ ] 지폐 클릭 → 현재 점수가 +15 증가하고 지폐가 사라진다
- [ ] 금괴 클릭 → 현재 점수가 +50 증가하고 금괴가 사라진다
- [ ] 클릭한 객체 위치에서 시각 피드백(예: 페이드아웃·스케일)이 짧게 보인 뒤 사라진다
- [ ] 화면 상단의 점수 표시가 즉시 새 값으로 갱신된다

### 4. 비누방울 클릭으로 감점

- **Given** — 라운드가 진행 중이고 화면에 비누방울(작은·큰) 하나 이상이 떠 있다
- **When** — 비누방울 객체 위를 클릭(또는 터치)한다
- **Then** — 해당 비누방울이 터지며 사라지고, 종류에 해당하는 점수만큼 현재 점수가 감소한다

성공 기준:
- [ ] 작은 비누방울 클릭 → 현재 점수가 -5 변경되고 비누방울이 사라진다
- [ ] 큰 비누방울 클릭 → 현재 점수가 -20 변경되고 비누방울이 사라진다
- [ ] 점수가 0인 상태에서 비누방울 클릭 → 점수가 음수로 표시된다 (예: -5)
- [ ] 비누방울이 사라질 때 "터지는" 시각 피드백이 보인다 (돈 클릭과 구별 가능한 효과)

### 5. 객체를 놓침 (땅 도달)

- **Given** — 라운드가 진행 중이고 화면에 객체 하나 이상이 떨어지고 있다
- **When** — 객체가 클릭되지 않은 채 화면 아래 경계(땅)에 도달했다
- **Then** — 객체가 화면에서 사라진다. 점수는 변하지 않는다

성공 기준:
- [ ] 돈이 땅에 닿음 → 점수는 그대로, 돈만 사라진다
- [ ] 비누방울이 땅에 닿음 → 점수는 그대로, 비누방울만 사라진다
- [ ] 놓친 객체에는 별도 페널티 표시가 나타나지 않는다

### 6. 시간 경과에 따른 가속

- **Given** — 라운드가 시작되어 시간이 흐르고 있다
- **When** — 라운드 시작 후 시간이 지난다
- **Then** — 시간이 지날수록 객체 생성 빈도와 낙하 속도가 증가한다

성공 기준:
- [ ] 라운드 0~10초 구간보다 50~60초 구간에서 동시에 화면에 떠 있는 객체 평균 개수가 더 많다
- [ ] 라운드 0~10초 구간보다 50~60초 구간에서 객체가 화면 상단에서 하단까지 도달하는 평균 시간이 더 짧다
- [ ] 가속은 단계적·연속적이며 사용자가 인지 가능한 변화로 나타난다 (한 번에 급변하지 않음)

### 7. 라운드 종료와 결과 화면

- **Given** — 라운드가 진행 중이고 남은 시간이 1초 이하다
- **When** — 남은 시간이 0이 된다
- **Then** — 객체 생성·낙하가 멈추고 결과 화면이 표시된다

성공 기준:
- [ ] 남은 시간 0 → 새 객체가 더 이상 생성되지 않는다
- [ ] 남은 시간 0 → 화면에 남아 있던 객체가 사라지고 결과 화면이 표시된다
- [ ] 결과 화면에 최종 점수가 표시된다
- [ ] 결과 화면에 종류별 잡은 개수가 표시된다 (동전 / 지폐 / 금괴 / 작은 비누방울 / 큰 비누방울)
- [ ] 결과 화면에 "다시하기" 버튼과 "메뉴로" 버튼이 표시된다

### 8. 최고 점수 갱신

- **Given** — 라운드가 종료되어 결과 화면이 표시되고, 직전 저장된 최고 점수보다 이번 점수가 높다
- **When** — 결과 화면이 표시된다
- **Then** — "최고 점수 갱신!" 같은 강조 표시가 함께 나타나고, 다음 메뉴 진입 시 새 최고 점수가 반영된다

성공 기준:
- [ ] 직전 최고점 100, 이번 점수 120 → 결과 화면에 최고점 갱신 강조가 표시된다
- [ ] 직전 최고점 100, 이번 점수 80 → 최고점 갱신 강조가 표시되지 않는다
- [ ] 최고점 없음 상태에서 첫 라운드 종료 → 어떤 양의 점수든 최고점으로 기록되고 갱신 강조가 표시된다
- [ ] 결과 화면 이후 메뉴에 진입 → 새 최고점이 메뉴에 반영되어 보인다
- [ ] 음수 점수로 종료 → 최고점에 기록되지 않는다 (기존 최고점이 있다면 유지)

### 9. 다시하기

- **Given** — 결과 화면이 표시된 상태
- **When** — "다시하기" 버튼을 클릭한다
- **Then** — 다시 3-2-1 카운트다운이 진행된 뒤 새 라운드가 시작된다

성공 기준:
- [ ] "다시하기" 클릭 → 결과 화면이 사라지고 카운트다운이 시작된다
- [ ] 새 라운드 시작 시점에 점수 0, 남은 시간 60초로 초기화되어 있다

### 10. 메뉴로 돌아가기

- **Given** — 결과 화면이 표시된 상태
- **When** — "메뉴로" 버튼을 클릭한다
- **Then** — 메뉴 화면으로 돌아가며, 갱신된 최고점이 반영되어 있다

성공 기준:
- [ ] "메뉴로" 클릭 → 결과 화면이 사라지고 메뉴 화면이 보인다
- [ ] 직전 라운드에서 최고점이 갱신되었다면 메뉴의 최고점 표시가 새 값이다

### 11. 부스터 충전 (200점 임계점 통과)

- **Given** — 라운드가 진행 중이고, 현재 보유 부스터는 N개이며, 현재 점수가 직전 임계점(200의 배수) 아래에 있다
- **When** — 점수 변화로 다음 200점 배수 임계점(200·400·600…)을 처음 도달하거나 넘는다
- **Then** — 보유 부스터가 N+1개로 증가하고, 부스터 버튼이 활성 상태로 표시된다

성공 기준:
- [ ] 점수 195 → 동전(+5) 클릭으로 200 도달 → 부스터 보유 +1
- [ ] 점수 190 → 지폐(+15) 클릭으로 205 도달 → 부스터 보유 +1
- [ ] 임계점 통과 직후 화면의 부스터 카운트 표시가 즉시 갱신된다 (지연 없음)
- [ ] 같은 라운드 안에서 같은 임계점은 다시 발급되지 않는다 (예: 점수 210 → 비누방울로 150 감점 → 다시 동전으로 210 회복해도 200 임계점 부스터는 추가 발급 안 됨)
- [ ] 한 번의 점수 증가가 여러 임계점을 동시에 넘으면 넘은 임계점 수만큼 발급된다 (예: 점수 190에서 금괴(+50) 클릭으로 240 도달 → 200 임계점 1회 통과로 +1 / 점수 380에서 두 번의 클릭으로 410 도달했고 그 사이 400을 처음 넘었다면 +1)
- [ ] 새 라운드 시작 시 보유 부스터는 0으로 초기화된다 (직전 라운드 미사용 부스터는 이월되지 않는다)
- [ ] 음수 점수에서 0~199 구간으로 회복해도 부스터는 발급되지 않는다

### 12. 부스터 발동 (3초 모드 진입)

- **Given** — 라운드가 진행 중이고, 보유 부스터가 1개 이상이며, 부스터 모드가 활성 상태가 아니다
- **When** — 부스터 버튼을 클릭(터치)한다
- **Then** — 보유 부스터가 1 감소하고, 3초 동안 "부스터 모드"에 진입한다. 이 동안 비누방울 생성이 중단되고, 돈은 평소 대비 동전 5배·지폐 3배·금괴 1배(그대로) 비율로 대량 생성된다

성공 기준:
- [ ] 보유 부스터 2개 상태에서 버튼 클릭 → 보유 1개로 감소하고 부스터 모드 진입 표시(시각 강조)가 나타난다
- [ ] 부스터 모드 진입 시각부터 정확히 3초간 모드가 유지된다 (3초 후 자동 종료)
- [ ] 부스터 모드 동안 새 비누방울이 한 개도 생성되지 않는다 (작은·큰 모두)
- [ ] 부스터 모드 동안 동전 생성 빈도가 평소 대비 약 5배다
- [ ] 부스터 모드 동안 지폐 생성 빈도가 평소 대비 약 3배다
- [ ] 부스터 모드 동안 금괴 생성 빈도는 평소와 동일하다 (1배)
- [ ] 부스터 모드 진입 시점에 이미 화면에 떠 있던 비누방울은 그대로 떨어진다 (강제 제거되지 않음). 클릭하면 평소와 동일하게 감점된다
- [ ] 부스터 모드 동안 떨어지는 돈을 클릭하면 평소와 동일하게 점수가 증가한다
- [ ] 부스터 모드 종료 직후부터는 평소 생성 패턴(돈+비누방울)으로 복귀한다
- [ ] 보유 부스터가 0개이면 부스터 버튼은 비활성 상태로 표시되고 클릭해도 모드가 발동되지 않는다

### 13. 부스터 중첩 방지

- **Given** — 부스터 모드가 활성 상태(3초 카운트 진행 중)이고, 보유 부스터가 1개 이상이다
- **When** — 부스터 버튼을 다시 클릭한다
- **Then** — 추가 발동되지 않는다. 보유 부스터 수와 남은 모드 시간이 변하지 않는다

성공 기준:
- [ ] 부스터 모드 활성 중 버튼 클릭 → 보유 부스터 변화 없음, 모드 남은 시간 변화 없음
- [ ] 부스터 모드 활성 중에는 버튼이 시각적으로 비활성 상태로 보인다 (모드 종료 후 다시 활성으로 복귀)
- [ ] 부스터 모드 종료 직후 버튼 클릭 → 정상적으로 새 모드 발동 (보유 -1, 3초 재시작)

## 불변 규칙

### 시각 식별

- 돈과 비누방울은 색·모양 중 하나만으로도 첫눈에 구분할 수 있어야 한다 (색맹 사용자도 모양만으로 구분 가능)
- 돈 3종 사이, 비누방울 2종 사이도 시각적으로 구분 가능해야 한다

### 클릭 가능성

- 모든 객체의 클릭 가능 영역은 모바일에서 최소 44×44 CSS px 이상이다
- 두 객체가 시각적으로 겹쳐 있어도, 클릭 시 사용자가 보기에 "위에 있는" 객체가 우선 반응한다

### 반응성

- 객체 클릭 → 점수 갱신·객체 제거가 같은 화면 프레임에서 보일 정도로 즉각적이다 (사용자가 지연을 느끼지 않는 수준)
- 게임 화면은 일반 데스크톱·모바일 브라우저에서 60초 동안 끊김이 인지되지 않을 정도로 부드럽게 동작한다

### 반응형

- 게임은 모바일 세로 화면과 데스크톱 가로 화면 모두에서 정상 동작한다
- 화면 크기에 관계없이 점수·남은 시간 표시는 항상 보인다

### 테마

- 시스템이 다크 모드일 때 결과 화면·메뉴·게임 보드가 모두 다크 톤으로 표시된다
- 시스템이 라이트 모드일 때 모두 라이트 톤으로 표시된다
- 어느 테마에서도 돈·비누방울의 시각 식별성이 유지된다

### 데이터 영속성

- 최고 점수 외 어떤 사용자 데이터도 저장하지 않는다 (라운드 기록·플레이 횟수 등 저장 안 함)
- 부스터 보유 수는 현재 라운드 안에서만 유효하다 (라운드 종료 시 미사용 부스터는 폐기되고, 결과 화면이나 다음 라운드에 이월되지 않는다)

### 부스터

- 부스터 모드 지속 시간은 발동 시각 기준 3초로 고정된다 (시간 가속·점수 변화·라운드 잔여 시간의 영향을 받지 않는다)
- 부스터 모드 중에도 라운드 잔여 시간은 평소와 동일하게 흐른다 (시간 정지·연장 없음)
- 라운드 잔여 시간이 3초 미만일 때 부스터를 발동하면 라운드 종료 시점에 부스터 모드도 자연 종료된다 (라운드 연장 없음)
- 부스터 모드가 끝나도 시간 가속 곡선은 모드와 무관하게 연속이다 (모드 진입 전과 종료 후의 가속 단계가 자연스럽게 이어진다)

## 의존성

- 떨어지고 떠 있고 클릭에 반응하는 게임 보드를 단일 페이지로 제공할 수 있는 웹 런타임 환경

## 미결정 항목

- **종류별 점수 값의 정확한 튜닝**: 현재 동전+5 / 지폐+15 / 금괴+50 / 작은 비누방울-5 / 큰 비누방울-20을 기준으로 두었으나, 플레이 테스트 후 균형 조정 가능
- **가속 곡선의 정확한 형태**: "시간이 지날수록 빨라진다"는 합의했으나 함수 형태(선형·지수 등)는 plan 단계에서 결정
- **객체 종류별 등장 빈도 비율**: 동전:지폐:금괴, 작은:큰 비누방울 비율은 plan·튜닝 단계 결정
- **객체의 구체 시각 디자인**: 이모지·일러스트·아이콘 중 무엇으로 표현할지 wireframe 단계에서 결정
- **부스터 모드 생성 배율의 정확한 튜닝**: 동전 5배·지폐 3배·금괴 1배를 기준으로 두되, 플레이 테스트 후 균형 조정 가능
- **부스터 버튼·카운트 UI 위치 및 시각 디자인**: 게임 보드 HUD 어디에 배치할지, 모드 활성 중 화면 효과(테두리 글로우 등)는 wireframe 단계에서 결정
